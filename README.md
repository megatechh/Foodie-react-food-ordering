# Foodie — React Food Ordering Frontend

A modern, responsive food-ordering frontend built with React + Vite.

## Features
- Responsive home, menu, food details, cart, checkout, wishlist, offers, about and orders pages
- Search, category filters, veg/non-veg filters and sorting
- Cart + wishlist persisted in localStorage
- Dark/light mode persisted in localStorage
- Demo checkout and order confirmation
- Modern responsive UI and animations
- Uses Unsplash image URLs for food photography

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the local Vite URL shown in the terminal.

This is a frontend-only project. Payment, authentication, database and real delivery tracking are demo UI flows.
